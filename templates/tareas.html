Guía de Uso: Tablero de Tareas

Este tablero permite organizar las actividades operativas asociadas a los clientes del CRM:

  • Filtros rápidos: Usa las pestañas "Pendientes", "En Progreso" o "Completadas" para filtrar los registros en la tabla.
  • Gestión del Tiempo: El sistema calcula automáticamente los días restantes. Las tareas vencidas se resaltarán en color rojo para priorizar su atención.
  • Actualizar Estado: Si tienes una tarea asignada, pulsa el botón "▶ Iniciar" para cambiar su estado, o "✓ Completar" para marcarla como finalizada.
  • Asignar Tarea: Si eres administrador, puedes pulsar "+ Nueva Tarea" para seleccionar un cliente, el responsable del trabajo, el tipo de actividad y su fecha límite.
